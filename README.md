# homeswithochuko.com

Write and edit blog posts at **https://homeswithochuko.com/admin** (sign in with GitHub).
Posts go live about a minute after you click **Publish**.

- Pages: the .html files in this folder
- Blog posts: content/blog/*.md (managed by the editor)
- Photos uploaded in the editor: images/uploads/
- Lead form endpoint, phone, links: site.js (SITE_CONFIG)
- Netlify builds the site with `npm run build` (build.js) into /dist
- RSS feed for social auto-posting: https://homeswithochuko.com/blog/feed.xml
